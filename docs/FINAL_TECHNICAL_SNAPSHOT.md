# FINAL TECHNICAL SNAPSHOT
GramVyapar AI (Phase 8 Demo Freeze)

## Product Thesis
- **Eligibility ≠ Viability**: Official scheme eligibility is not the same as business survivability.
- **AI explains. Deterministic logic decides**: AI provides plain-language explanations; financial engines determine numbers and risk limits.
- **Voice improves accessibility. It does not make financial decisions**: Voice reduces friction for rural entrepreneurs but all critical inputs require explicit confirmation.

## Architecture
- **Presentation**: Next.js (App Router), React, Tailwind CSS
- **Validation**: Zod (strict schema enforcement)
- **Domain**: Deterministic Dairy Economics, Financial Structuring, Stress Testing, Decision Engine
- **Evidence**: Nominatim (Geocoding), OSM / Overpass API (Hyper-Local POI mapping), Open-Meteo (Weather context)
- **AI**: Gemini (Explainable Advisory only)
- **Voice**: Browser Speech APIs (SpeechRecognition / speechSynthesis) + custom deterministic parsing

## Authoritative Engines
- `calculateFinancialAssessment`: Derives cash flows, project costs, and financing requirements deterministically.
- `calculateStressAssessment`: Creates a degraded economic scenario based on configured rules (e.g. 20% milk yield drop).
- `evaluateDecision`: Top-down hierarchical logic assigning `PROCEED`, `MODIFY`, or `HIGH_RISK` and specific reason codes based exclusively on the deterministic calculations.

## AI Boundary
- **Does NOT**: calculate project cost, calculate funding gap, run stress formulas, choose deterministic decision, classify OSM POIs, approve loans, determine official scheme eligibility, or parse voice financial numbers.
- **DOES**: explain the deterministic decision, localize advisory text into regional languages, produce grounded recommended verifications, and summarize local context.

## Voice Boundary
- **Input**: Uses browser STT (Speech Recognition) mapping `hi-IN`, `en-IN`, `bn-IN`, `mr-IN`, `ta-IN`.
- **Parser**: Hand-rolled deterministic parser. Does NOT use Gemini. Maps words like "seventy five thousand" or "one lakh" strictly to numeric digits.
- **Safety**: Extracts candidate values which MUST be explicitly confirmed by the human before being applied to the authoritative form state.
- **Output**: Uses browser TTS (Speech Synthesis). Reads exclusively from the structured `AdvisoryResult` payload generated by Gemini. Stops instantly on state changes.

## Financial Assumptions
- **Interest Rate**: 8% annual
- **Tenure**: 7 years
- **Moratorium**: 6 months
- **Repayment Frequency**: Quarterly (amortizing over 26 quarters after moratorium)
- **Capitalization**: Simple interest capitalized during moratorium.

## Stress Scenario (Primary Downside)
- **Milk Yield Change**: -20%
- **Feed Cost Change**: +15%
- The stress engine strictly applies these factors and recalculates the assessment, leaving loan principal and repayment burden unchanged.

## Evidence Semantics
- **No mapped evidence != No competition**: Unmapped POIs are properly categorized as `INSUFFICIENT` or `LIMITED`, avoiding false claims of "untapped opportunity".
- **Radius Strategy**: Independent 5km and 10km radii queries.
- **Classification**: Strictly differentiates Dairy-Specific activity, Potential Sales Channels, and Support Infrastructure.

## Failure Isolation
- **Nominatim / Geocoding**: Fails gracefully; evidence goes to `UNAVAILABLE`.
- **Overpass API**: Fails gracefully; partial or total failure sets confidence flags to `INSUFFICIENT` without crashing the financial engine.
- **Open-Meteo**: Fails gracefully; ignored if unavailable.
- **Gemini AI**: Fails gracefully; AI section shows "unavailable" state while deterministic decision and financial charts remain perfectly functional.
- **Voice**: Gracefully degrades; text typing fallback always available.

## Known Limitations & Judge-Safe Technical Claims
- The system does not determine official loan scheme eligibility.
- Evidence mapping is dependent on OSM coverage density in rural areas; sparse mapping is handled safely via UI language.
- Stress buffer is a prototype assumption (₹10,000), not an officially vetted banking standard.
